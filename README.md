# habits

Трекер привычек для командной строки на C++17. Учебный проект: можно завести привычки,
отмечать их по дням, смотреть серии (streak), замораживать пропущенный день и выгружать данные в CSV.

```
$ habits list
Today is 2026-10-10 (Sa)

 ID  Today  Habit             Freezes  Streak
  1  [x]    Read 20 pages           2  15 days
  2  [ ]    Morning exercise        1  11 days  !
  3  [x]    Learn C++               0  6 days

Done today: 2 of 3
! means the streak will be lost if you skip today (or use: habits freeze ID)
```

## Сборка

Нужен компилятор с поддержкой C++17 и CMake 3.16 или новее.

```
cmake -S . -B build
cmake --build build
```

Программа появится в папке `build` (на Windows с Visual Studio в `build/Debug`).

## Команды

| Команда | Что делает |
|---|---|
| `habits add NAME` | добавить привычку |
| `habits list` | список привычек и отметки за сегодня |
| `habits done ID [DATE]` | отметить привычку как сделанную |
| `habits undo ID [DATE]` | убрать отметку или заморозку |
| `habits freeze ID [DATE]` | заморозить пропущенный день, чтобы не потерять серию |
| `habits rename ID NAME` | переименовать привычку |
| `habits remove ID` | удалить привычку со всеми отметками |
| `habits log [DAYS]` | таблица за последние дни (по умолчанию 14, максимум 60) |
| `habits stats` | серии и процент выполнения |
| `habits export FILE` | сохранить все дни в CSV файл |
| `habits menu` | меню с цифрами вместо команд |
| `habits help` | справка |

`DATE` это `today`, `yesterday` или дата в виде `2026-10-09`. Если дату не писать, берётся сегодня.
Будущие дни отмечать нельзя.

## Пример

```
$ habits add Read 20 pages
Added habit 1: Read 20 pages

$ habits done 1 yesterday
Read 20 pages: done on 2026-10-08, streak 1 day

$ habits done 1
Read 20 pages: done on 2026-10-09, streak 2 days

$ habits log 7
                    Sa Su Mo Tu We Th Fr
 ID  Habit           3  4  5  6  7  8  9
  1  Read 20 pages                  x  x

x - done, . - missed, from 2026-10-03 to 2026-10-09

$ habits stats
 ID  Habit          Since       Done  Days  Percent  Streak  Best
  1  Read 20 pages  2026-10-08     2     2     100%       2     2

$ habits export habits.csv
Saved to habits.csv
```

Готовые данные для проверки лежат в папке `examples`:

```
./build/habits -f examples/habits.txt stats
```

## Как считается серия

- Текущая серия это сколько дней подряд привычка сделана. Если сегодня ещё не отмечено,
  серия считается до вчера, поэтому она не обнуляется с утра.
- Если пропущен хотя бы один целый день, серия начинается с нуля.
- Лучшая серия это самая длинная серия за всё время.
- Процент это сделанные дни, делённые на все дни с начала привычки до сегодня.

## Заморозка серии

Если день пропущен, его можно заморозить, и серия не обнулится:

```
$ habits freeze 1 yesterday
Read 20 pages: 2026-10-09 is frozen, streak 7 days, freezes left: 0
```

- За каждые 7 сделанных дней привычка получает одну заморозку.
- Замороженный день не ломает серию, но и не увеличивает её.
- Заморозить можно только пропущенный день, не раньше начала привычки и не в будущем.
- Если потом отметить этот день через `done`, заморозка вернётся в запас.
- `habits undo ID DATE` убирает заморозку.
- В таблице `log` замороженный день показан звёздочкой, в `list` сегодня это `[*]`.
- На процент заморозка не влияет: замороженный день считается несделанным.

## Где лежат данные

Данные хранятся в файле `habits.txt` в той папке, где запущена программа.
Другой файл можно указать через `-f`:

```
habits -f work.txt list
```

Файл текстовый, его можно открыть и поправить в любом редакторе:

```
habit|1|2026-10-01|Read 20 pages
done|1|2026-10-01
done|1|2026-10-02
freeze|1|2026-10-03
```

Если в файле ошибка, программа скажет номер строки и ничего не будет менять.

## CSV

В файле одна строка на каждый день каждой привычки:

```
habit_id,habit,date,weekday,done,frozen
1,Read 20 pages,2026-10-08,Th,1,0
1,Read 20 pages,2026-10-09,Fr,0,1
```

## Просмотр в браузере

В папке `web` лежит страница на React. Открой `web/index.html` в браузере и выбери CSV файл,
который сделала команда `habits export`. Для каждой привычки покажется календарь и серии.
Нужен интернет, потому что React подключается по ссылке.

Сверху показывается огонёк с общей серией: сколько дней подряд сделана хотя бы одна привычка.

- огонёк горит, если сегодня уже есть отметка
- огонёк бледный, если серия есть, но сегодня ещё ничего не отмечено
- огонёк синий, если сегодняшний день заморожен
- огонёк серый, если серии нет

Замороженные дни в календаре синие, в кружках недели вместо огонька снежинка.

Под ним кружки за последние 7 дней, а у каждой привычки свой маленький огонёк с её серией.
Страница показывает данные на момент экспорта, поэтому после новых отметок нужно сделать `habits export` ещё раз.

## Тесты

```
cd build
ctest --output-on-failure
```

или напрямую `./build/run_tests`. Тесты проверяют даты (високосные годы, переход через месяц и год),
серии, заморозку, команды, сохранение в файл и CSV.

## Как устроен код

```
src/
  main.cpp       разбор аргументов и вызов команд
  commands.cpp   команды, вывод таблиц, меню
  date.cpp       работа с датами
  stats.cpp      серии и проценты
  storage.cpp    чтение и запись файла с данными
  export.cpp     экспорт в CSV
  habit.h        структура привычки
tests/
  run_tests.cpp
web/
  index.html, app.js, style.css
examples/
  habits.txt, habits.csv
```

Главная идея: дата внутри программы хранится как одно число, количество дней от 1 января 1970 года.
Тогда «следующий день» это просто `+1`, а отметки привычки лежат в `std::set<int>`.

## Что пока не работает

- привычки только на каждый день, нельзя задать «3 раза в неделю»
- заморозки не сгорают и копятся без ограничения
- заморозка ставится только командой, сама за пропущенный день она не тратится
- на Windows русские названия в консоли могут показываться неправильно, перед запуском помогает `chcp 65001`
- если открыть CSV с русскими названиями в Excel, кодировку нужно выбрать UTF-8
